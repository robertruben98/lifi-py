# lifi-py

Python client for the LI.FI API (bridge + DEX aggregator, any-to-any cross-chain). Sync + async, Pydantic v2.

## Install

```bash
pip install lifi-py
```

The distribution is `lifi-py`; the import package is `lifi_py`.

## Quick start

```python
import lifi_py
```

See the [API reference](api.md) for the full surface.
